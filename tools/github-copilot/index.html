GitHub Copilot

AI pair programmer that works inside your existing editor.

DevelopmentAI Coding AssistantsFreemium

Overview

GitHub Copilot is an AI coding assistant from GitHub. It works inside VS Code and other editors, on GitHub.com and in the terminal, with code completions, chat and an agent mode that can plan and make changes across your project.

Paid plans add unlimited completions, Copilot cloud agent, code review on pull requests and a choice of models from several providers. Usage beyond completions is measured in GitHub AI Credits, which each plan includes every month. There's a free plan for individuals, free access for verified students, and Business and Enterprise plans for organizations.

Key features

  • Code completions

    Inline suggestions as you type: 2,000 a month on Free, unlimited on paid plans.

  • Chat and agent mode

    Ask questions about your code, or let an agent plan and edit across files. Free supports agent mode too.

  • Copilot cloud agent

    Assign tasks that Copilot works on in the cloud and returns as pull requests, from the Pro plan.

  • Code review

    AI review of pull requests on GitHub, included from the Pro plan.

  • Copilot CLI

    Use Copilot from the terminal, available on every plan including Free.

  • Model choice

    Choose from models across providers; Pro+ and Max add premium models.

Best for

  • AI code completions in your existing editor
  • Explaining and refactoring code with chat
  • Delegating tasks to an agent that opens pull requests
  • AI review of pull requests on GitHub
  • Organizations standardising on GitHub's AI tools

Strengths & limitations

Strengths

  • Works in the editor you already use, including VS Code and JetBrains IDEs.
  • Deep integration with GitHub repositories, issues and pull requests.
  • A free plan, plus free access for verified students.
  • Pro is $10/mo, with unlimited completions and code review.

Limitations

  • The free plan has limited chat and agent usage and 2,000 completions a month.
  • Chat, agents and code review consume monthly AI credits; heavy use needs a higher plan.
  • Premium models need Pro+ ($39/mo) or Max ($100/mo).
  • Business and Enterprise are billed per user, at $19 and $39 a month.
  • Enterprise requires GitHub Enterprise Cloud.

Pricing

Free plan available. Paid plans include a monthly allowance of GitHub AI Credits for chat, agents and code review. Prices are in USD. Verified students can use Copilot free.
