Penpot

Open-source design and prototyping platform.

DesignUI/UX DesignOpen Source
Visit Penpot (opens official site in a new tab) Figma vs Penpot

Overview

Penpot is an open-source design and prototyping platform for product teams. Designers and developers work in the same browser-based workspace, with components, variants, shared libraries and interactive prototypes, and designs are built on open standards such as SVG, CSS and HTML.

You can use Penpot in the cloud or self-host it on your own infrastructure, including air-gapped environments. Layouts use CSS Flex and Grid, design tokens are built in, and the Inspect tab gives developers ready-to-use code. A free, open MCP server lets AI agents read and edit Penpot files.

Key features

  • Design and prototyping

    Design interfaces in the browser and link screens into interactive prototypes to test flows.

  • Components and variants

    Build design systems with components, variants and shared libraries, without plugins.

  • Native design tokens

    Built-in tokens in the open W3C DTCG format, with token sets and themes.

  • CSS Flex and Grid layouts

    Responsive layouts that follow the same rules as CSS, so designs map directly to code.

  • Inspect mode

    Developers get SVG, CSS and HTML for any element from the Inspect tab, on every plan.

  • MCP server and plugins

    A free, open MCP server connects AI agents to your files, alongside a plugin system and open API.

Best for

  • UI and UX design for web and mobile products
  • Interactive prototypes and user flows
  • Design systems with tokens, components and variants
  • Design-to-code handoff for developers
  • Teams that need self-hosting or data control

Strengths & limitations

Strengths

  • Open source, with the option to self-host on your own servers.
  • The free cloud plan includes all core design and prototyping features.
  • Built on open standards (SVG, CSS, HTML), so designs are close to production code.
  • Paid cloud pricing is predictable: the Unlimited plan is capped at $175/mo.

Limitations

  • The free cloud plan is limited to 8 team members (viewers are unlimited) and 10 GB of storage.
  • Self-hosting requires a Linux server, Docker knowledge and managing the deployment yourself.
  • Free self-hosting comes with community support only.
  • SSO, a central admin console and audit logs need the Enterprise plan.
  • Runs in the browser only; there's no official desktop app.

Pricing

The cloud version has a free plan, and self-hosting the open-source version is free for unlimited users. Prices are in USD; discounts are available for non-profits, education and open-source projects.
