Postman

API platform for designing, sending, testing and documenting requests.

DevelopmentAPIs & TestingFreemium
Visit Postman (opens official site in a new tab)

Overview

Postman is a platform for building and testing APIs. Its API client lets you design, send, debug and test requests across HTTP, GraphQL, gRPC, WebSocket and MQTT, using collections, environments and scripts.

Postman also covers API specifications, mock servers, documentation and monitoring, and includes Postman AI, which uses monthly AI credits. It runs as a desktop app for Windows, macOS and Linux, on the web, in VS Code and from the command line with the Postman CLI. Free and Solo are single-user plans; Team and Enterprise add collaboration and governance.

Key features

  • Multi-protocol API client

    Send and debug requests across HTTP, GraphQL, gRPC, WebSocket and MQTT.

  • Collections and environments

    Organise requests and switch variables between environments.

  • Automated testing

    Write tests and run collections, with data-driven testing on Solo and up.

  • Specs and mock servers

    Create and version API specifications and mock servers.

  • Documentation and monitoring

    Publish API docs and monitor APIs, with custom branding on paid plans.

  • Postman AI and CLI

    AI help with monthly credits, plus the Postman CLI for CI/CD pipelines.

Best for

  • Testing and debugging APIs
  • Documenting APIs for teams
  • Mocking APIs during development
  • Automated API tests in CI/CD
  • Sharing collections across a team

Strengths & limitations

Strengths

  • A free plan with the API client, specs and mock servers.
  • Supports many API protocols in one tool.
  • Available on desktop, web, VS Code and the command line.
  • Solo is affordable at $9 a month, billed yearly.

Limitations

  • Free and Solo are single-player plans; collaboration needs Team.
  • AI usage beyond monthly credits is billed per credit.
  • Role-based access control needs the Team plan.
  • Packages aren't available on the free plan.
  • The web app needs the Desktop Agent to reach local and private networks.
