Vercel

Deploy and scale modern web applications.

DevelopmentHosting & DeploymentFreemium
Visit Vercel (opens official site in a new tab)

Overview

Vercel is a cloud platform for deploying and scaling web applications. Import a Git repository and Vercel builds and deploys it automatically, with a preview URL for every push, a global CDN, automatic HTTPS and serverless functions. Vercel also maintains the Next.js framework.

Functions run on Fluid compute, which is billed by active CPU time and reuses instances to cut costs. Vercel also offers infrastructure for AI apps and agents, including the AI SDK, an AI Gateway to hundreds of models, sandboxes and v0, its AI app builder. The Hobby plan is free; Pro adds team collaboration and a monthly usage credit, with usage billed on demand after that.

Key features

  • Git-based deploys

    Automatic CI/CD from GitHub and other Git providers, with HTTPS on every deployment.

  • Preview deployments

    Every pull request gets its own URL on production-equivalent infrastructure.

  • Fluid compute

    Serverless functions billed by active CPU, with concurrency and minimal cold starts.

  • Global CDN and firewall

    A global CDN with DDoS mitigation and a Web Application Firewall.

  • AI infrastructure

    The AI SDK, an AI Gateway to hundreds of models, sandboxes and durable workflows.

  • v0

    Vercel's AI app builder that generates apps and deploys them to Vercel (paid add-on).

Best for

  • Hosting Next.js and other frontend frameworks
  • Preview environments for every pull request
  • Serverless APIs and backends
  • Deploying AI apps and agents
  • Marketing sites and ecommerce storefronts

Strengths & limitations

Strengths

  • Very fast setup: import a repo and deploy in seconds.
  • Preview URLs for every pull request.
  • Made by the team behind Next.js, with first-class support.
  • A free Hobby plan with 100 GB of Fast Data Transfer.

Limitations

  • Pro is $20/mo per seat, plus on-demand usage beyond the included $20 credit.
  • Usage-based pricing across many metrics can be harder to predict.
  • Hobby has fixed usage limits rather than on-demand billing.
  • Some features, such as v0, are paid add-ons.
  • Contractual SLAs and multi-region compute need Enterprise.

Pricing

Free Hobby plan. Pro includes a monthly usage credit, then bills usage on demand. Prices are in USD and exclude taxes. Pro has a 14-day free trial.
