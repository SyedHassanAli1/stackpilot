Cursor

AI-first code editor for writing, editing and understanding code.

DevelopmentAI Coding AssistantsFreemium

Overview

Cursor is an AI coding agent and code editor. Its desktop app offers an agent-first experience alongside a familiar editor, with AI chat, Tab completions and agents that can read and edit code across a whole project. Cursor also runs in your terminal, collaborates in Slack and reviews pull requests in GitHub.

Since 2026 Cursor has been owned by SpaceX, and new customers buy it through The X Subscription, a single subscription that covers Grok, Cursor and X. Plans include Cursor's own models, such as Grok and Composer; higher plans add Cloud Agents, Bugbot code review and third-party models from other providers. Existing customers can stay on their legacy Cursor plans.

Key features

  • Agent and Chat

    Ask an AI agent to plan, write and edit code across your project, or chat about your codebase.

  • Tab completions

    AI autocomplete that predicts your next edit as you type, on every plan including Free.

  • Cloud Agents and Automations

    Run agents in the cloud and automate recurring tasks, from the Premium plan.

  • Bugbot code review

    AI code review on GitHub pull requests, included from the Premium plan.

  • Cursor CLI

    Run agents from any terminal or script on macOS, Linux and Windows.

  • Model choice

    Cursor models such as Grok and Composer, plus third-party models at API list price on Premium and up.

Best for

  • Writing and refactoring code with an AI agent
  • Understanding and navigating large codebases
  • Automated code review on pull requests
  • Running coding agents from the terminal or in the cloud
  • Engineering teams standardising on one AI editor

Strengths & limitations

Strengths

  • Agent, Chat and Tab completions are all included on the free plan.
  • One tool across desktop, terminal, Slack and GitHub.
  • Available on macOS, Windows and Linux.
  • Plans scale from $8/mo up to Ultra, with Teams seats at matching prices.

Limitations

  • The free plan has limited usage.
  • The $8/mo Plus plan has no Cloud Agents, Bugbot or third-party models.
  • Third-party models are billed at API list price from prepaid credit, on top of the plan.
  • New plans are sold through The X Subscription, bundled with Grok and X.
  • Heavy agent use can need a higher plan; Super is $100/mo and Ultra $200/mo.

Pricing

Free plan available. Plans are sold through The X Subscription, which also covers Grok and X. Prices exclude tax. Existing customers can keep legacy Cursor plans such as Pro ($20/mo).
