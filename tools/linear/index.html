Linear

Issue tracking and product planning for software teams.

ProductivityProject ManagementFreemium
Visit Linear (opens official site in a new tab)

Overview

Linear is an issue tracker and planning tool for product and engineering teams. Teams track issues, run cycles, plan projects and roadmaps, and move quickly with keyboard-first navigation, light and dark themes, and integrations with GitHub and Slack.

Linear also includes AI features: Linear Agent and an agent platform are on every plan, and cloud coding sessions can work on issues, billed from prepaid AI credits that are opt-in. Business adds Triage Intelligence, Code Intelligence and Linear Insights. Linear runs in the browser, on Mac and Windows, and on iOS and Android.

Key features

  • Issue tracking

    Fast, keyboard-first issue tracking with custom workflows, labels and priorities.

  • Cycles and projects

    Plan work in cycles and projects, and track progress on roadmaps.

  • Linear Agent

    An AI agent and agent platform included on every plan.

  • Cloud coding sessions

    Let a coding agent work on issues in the cloud, billed from opt-in AI credits.

  • Triage and insights

    Triage Intelligence, Code Intelligence and Linear Insights on the Business plan.

  • Integrations

    Connect GitHub, Slack, Zendesk and Intercom, with an API for custom tools.

Best for

  • Bug and issue tracking for software teams
  • Sprint planning with cycles
  • Product roadmaps and project tracking
  • Customer requests from support tools
  • Engineering teams at startups and enterprises

Strengths & limitations

Strengths

  • Fast and focused, with keyboard-first navigation.
  • A free plan with unlimited members.
  • Desktop apps for Mac and Windows, plus native mobile apps.
  • 75% off Basic and Business for eligible non-profits.

Limitations

  • The free plan is limited to 2 teams and 250 issues.
  • Basic is limited to 5 teams; unlimited teams need Business.
  • AI coding sessions need prepaid AI credits on top of the plan.
  • SAML, SCIM and invoice billing need the Enterprise plan.

Pricing

Free plan available. Paid plans are billed per user, monthly or yearly; Enterprise is yearly only. AI coding sessions use opt-in, prepaid AI credits.
