DeepL

AI translation and writing tool for text and documents.

AI ToolsWriting & TranslationFreemium
Visit DeepL (opens official site in a new tab)

Overview

DeepL is an AI translation tool for text and whole documents. You can translate Word, PowerPoint, Excel and PDF files while keeping their original formatting, and use glossaries to keep terms consistent.

DeepL also offers DeepL Write for improving text, DeepL Voice for real-time speech translation, and an API for developers. The free web translator is limited; Pro plans add more characters, file translations and maximum data security, with Pro texts deleted after translation and never used for training.

Key features

  • Text translation

    Translate text in the web translator or desktop apps.

  • Document translation

    Translate Word, PowerPoint, Excel and PDF files while keeping their layout.

  • Glossaries

    Keep terminology consistent, with more glossaries on higher plans.

  • DeepL Voice

    Real-time speech translation, with 30 minutes per user each month on paid plans.

  • DeepL Write

    Improve and rephrase your writing, with Write Pro as an add-on.

  • DeepL API

    Add translation to your apps, with a free API plan for up to 500,000 characters a month.

Best for

  • Translating business documents
  • Multilingual websites and content
  • Communicating with international teams
  • Professional translators' workflows
  • Adding translation to apps via the API

Strengths & limitations

Strengths

  • Document translation that keeps the original formatting.
  • Pro texts are deleted after translation and not used for training.
  • A free API plan with 500,000 characters a month.
  • Paid plans include a 30-day free trial.

Limitations

  • The free translator has a much lower character limit than paid plans.
  • Individual includes only 3 file translations a month.
  • Translator plans don't include API access; the API needs a separate plan.
  • SSO and team administration need the Team plan or higher.
  • Files on free accounts aren't editable after translation.

Pricing

Free version available. Translator plans are billed per user; prices below are billed yearly, which saves about 16%. API plans are separate. Paid plans have a 30-day free trial.
